# AGENTS.md

This file provides guidance to agents when working with code in this repository.

## Project

SAP CAP (Cloud Application Programming) bookshop demo targeting SAP BTP with HANA, scaffolded with `@sap/cds-dk` v10. All project files live under `watsonx-challenge-2026/`.

## Stack

- **Runtime**: Node.js (`"type": "module"`)
- **Framework**: `@sap/cds` ^10 + `@cap-js/hana` ^3 (production)
- **Local dev DB**: `@cap-js/sqlite` ^3 (dev only — SQLite is auto-used when no HANA binding)
- **Deployment**: MTA (Multi-Target Application) via `mta.yaml`; build output goes to `gen/` (gitignored)

## Commands (run from `watsonx-challenge-2026/`)

```bash
cds watch          # dev server with hot-reload (preferred over npm start)
npm start          # cds-serve (no watch)
npx cds build --production   # generates gen/srv and gen/db for MTA deployment
npm ci             # install locked deps (used in MTA build)
```

> There are **no test scripts** defined. `@sap/cds-dk` ships its own test runner — add `cds.test()` in a `test/` directory if needed.

## CDS / Data Model Conventions

- Domain model namespace: `com.bookshop` — entities are in [`db/domain-model.cds`](watsonx-challenge-2026/db/domain-model.cds)
- Services expose entities via `SELECT` projections (not direct `entity X as Y`): see [`srv/admin-service.cds`](watsonx-challenge-2026/srv/admin-service.cds)
- CSV seed files must be named `<namespace>.<Entity>.csv` (e.g. `com.bookshop.Books.csv`) and placed in [`db/data/`](watsonx-challenge-2026/db/data/)
- Entity IDs are `String` (UUID strings), **not** `Integer` or `UUID` CDS type

## Key Paths

```
watsonx-challenge-2026/
  db/domain-model.cds   ← data model (namespace com.bookshop)
  db/data/              ← CSV seed data (loaded automatically by CAP)
  srv/admin-service.cds ← OData service definition
  app/                  ← UI frontend (currently empty)
  gen/                  ← build output (gitignored, generated by cds build)
  mta.yaml              ← BTP deployment descriptor
```

## Gotchas

- `gen/` is gitignored — never commit build artifacts; always regenerate with `npx cds build --production`
- `.cdsrc-private.json` and `default-*.json` are gitignored — used for local credential overrides; do not create them in tracked paths
- `@cds-models/` (typer output) is also gitignored
- The `app/` folder is intentionally empty — UI is not yet implemented
